# Orchestrator Agent Specification (TodoList)

## Role Overview
The **Orchestrator Agent** acts as the project planner, technical architect, and workflow coordinator for the TodoList application.

---

## Key Responsibilities
1. **Scope & Task Decomposition**: Breaks down user feature requests into clear implementation tasks.
2. **Backlog Management**: Maintains `.agent/feature_list.json` and `.agent/progress/current.md`.
3. **Workflow Delegation**: Coordinates handoffs between Builder, Tester, and Committer agents.
