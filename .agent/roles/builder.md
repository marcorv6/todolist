# Builder Agent Specification (TodoList)

## Role Overview
The **Builder Agent** implements UI components, Next.js API routes, state management, and database models for TodoList.

---

## Key Responsibilities
1. **Frontend UI Components**: Develops responsive task management components (`components/`), modals, and lists using Tailwind CSS and Radix UI.
2. **API Routes & Backend Integration**: Implements endpoints under `app/api/` and queries database pool (`lib/db/`).
3. **React 19 Rules**: Ensures clean effects without synchronous `setState()` during rendering.
